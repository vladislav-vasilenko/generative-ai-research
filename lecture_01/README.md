## Запуск локально

Команды выполняются **из корня репозитория**. Используйте Python 3.11 или 3.12.

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r lecture_01/requirements.txt
python -m jupyterlab lecture_01/lab_one_ru.ipynb
```

В Windows активация: `.venv\Scripts\activate`. Если уже установили корневой `requirements.txt`, повторная установка не нужна. Выберите ядро Python из `.venv`. Все этапы доступны на CPU; GPU не требуется.

Выполняйте ячейки сверху вниз через **Shift+Enter**. Полный запуск: **Kernel → Restart Kernel and Run All Cells**. В разделах есть условие, инструкция, код, рисунок и разбор. После изменения класса заново выполните ячейки, создающие его экземпляры.

## Частые затруднения

- **`NameError`**: не выполнена предыдущая ячейка. Перезапустите ядро и выполните всё по порядку.
- **`NotImplementedError`**: открыта версия с упражнениями. Заполните метод или перейдите к решениям.
- **Не совпадают device/dtype**: состояния и времена должны иметь одинаковые устройство и тип чисел.
- **OU разлетается при большой theta**: проверьте `theta * h < 2`; для точности нужно гораздо меньше единицы.
- **Гистограммы похожи при разном шуме**: автоматически изменился масштаб осей. Смотрите числа и задайте общие пределы.
- **Нет переходов между модами**: увеличьте время при прежнем малом шаге, попробуйте более близкие или широкие моды. Это может быть проблемой перемешивания.
- **HTML-анимация не отображается**: после просмотра кода выполните ячейку анимации заново.
- **Нужен MP4**: установите системный `ffmpeg`, затем передайте `save_path`. Python-пакет с похожим названием не заменяет программу.
