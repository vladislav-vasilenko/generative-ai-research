# Уточнения к исходным материалам

Оригиналы сохраняются побайтово; этот файл не исправляет их молча. Для источников даны SHA-256 и zero-based cell indexes в [manifest](references/materials_manifest.json). Ни одна исходная лабораторная автоматически не исполняется.

1. **Lab 2, Q3.3, markdown cell 59.** Для $\alpha_t=t$, $\beta_t=\sqrt{1-t}$ при $0\le t<1$ denominator $\beta_t^2\dot\alpha_t-\alpha_t\dot\beta_t\beta_t=1-t/2$. Его предел при $t\to1^-$ равен $1/2$, а не 0. В исходнике показано отдельное значение 0 при t=1; использовать его как алгебраическое продолжение нельзя. Производная beta в endpoint сингулярна, conditional Gaussian вырождается; используйте interior t и отдельно рассматривайте limit/marginal. Не доказывайте из этой опечатки общую невозможность marginal score.
2. **Lab 3, markdown cell 24.** При фиксированном классе y речь о $p_{\mathrm{data}}(x\mid y)$; встречающееся в пояснении `p_simple(x|y)` не должно превращать источник шума в распределение данных.
3. **Lab 3, Q3.2, cell 40.** Число image tokens равно $(H/p)(W/p)$, а не произведению смешанных h/w. В коде проверяйте divisibility и точное обратное unpatchify.
4. **Lab 3, Part 4, cell 55.** `logvar` означает $\log\sigma^2$, поэтому std = `exp(0.5*logvar)`. В пояснении встречается обозначение log sigma; следуйте выбранной параметризации consistently и сверяйте код/loss.
5. **Lecture 5.** CTMC state не следует обычной ODE/SDE в пространстве token IDs. Однако вектор вероятностей удовлетворяет ODE Колмогорова. Это разные уровни описания.
6. **Нумерация/даты.** Файлы и страница курса относятся к 2026; на некоторых титульных слайдах осталась дата 2025. В маршруте используем filenames, хеши и реальные PDF pages, а не эту подпись.
7. **Inference и training.** ComfyUI VAE reconstruction не измеряет ELBO/KL и не обучает VAE. CFG slider не добавляет unconditional training; distilled checkpoint может не поддерживать обычный guidance sweep.

Это целевые уточнения для маршрута, не утверждение о полном аудите всех решений/ячеек и не официальное errata MIT.
