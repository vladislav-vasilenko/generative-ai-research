# Закреплённые сторонние исходники

Этот каталог нужен для воспроизводимого чтения архитектуры и локального PyTorch reference. Он не является отдельным приложением и не предназначен для установки целиком.

- `kandinsky-6/`, `kvae/`, `kvae-audio/` — выбранные неизменённые исходники официальных проектов; LICENSE сохранены.
- `hf/` — model cards и configs конкретных revisions; весов моделей здесь нет.
- `source-manifest.json` — source URLs, revisions, SHA-256 и размеры файлов.

Начните с [карты проекта](../README.md), [ручного notebook](../notebooks/00_manual_experiment_comfy_mlx_film.ipynb) и [границ проверенного](../STATUS.md). Собственная исследовательская реализация находится в `../labkit/`; утилиты — в `../scripts/`. Внутри сторонних snapshots правки не вносятся молча.
